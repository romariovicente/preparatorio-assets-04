# PREPARATÓRIO — acervo 3D 04

Snapshot dos arquivos usados no protótipo educacional PREPARATÓRIO, por Romario Vicente Amaro. Este repositório hospeda somente parte do acervo, organizado para o carregamento gradual do jogo.

Os arquivos possuem autores e licenças individuais e **não** recebem uma licença coletiva. Há conteúdo de uso não comercial, modelos CC BY / CC BY-SA / CC BY-NC-SA e fontes cujos metadados não informam licença. A presença aqui não concede direitos adicionais nem confirma autoria ou direitos de redistribuição. Consulte [os créditos e restrições de cada modelo](THIRD_PARTY_ASSETS.md). Não utilize o conjunto comercialmente nem redistribua modelos sem verificar a licença individual.

Livros PDF não integram esta publicação pública. Os originais permanecem preservados no computador do criador.

O arquivo `asset-manifest.json` registra tamanho e SHA-256 de cada arquivo deste snapshot. A página estática entrega os modelos como arquivos; o código do jogo permanece em [preparatorio](https://github.com/romariovicente/preparatorio).
